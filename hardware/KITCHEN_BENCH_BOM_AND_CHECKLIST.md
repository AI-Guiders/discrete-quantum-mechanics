# Полный инженерный паспорт, спецификация (BOM) и 20-узловая физика реального кухонного стенда `Tang Nano 9K`

Этот документ сводит воедино всю физику реального настольного стенда (`System_1 -> ... -> System_20`), формально доказанную в `lean/MtCarrier/UnifiedOperators.lean` (`checkCascadedSystemInteractionAndInformationLossOp` и `checkFinitePerturbationCalibrationAndStringMultiverseDemystificationOp`), промоделированную в `hardware/kitchen_bench_mosfet_coil.cir` (LTspice) и `hardware/cuboctahedron_carrier_asic.v` (Icarus Verilog), и управляемую через MCP-сервер `hardware/cuboctahedron_mcp_server.py` (`cuboct_calibrate_kitchen_bench`).

## 2. Комплектация стенда (Bill of Materials — BOM)

1. **Плата управления:** `Sipeed Tang Nano 9K` (`Gowin GW1NR-9C`, встроенный кварц $27{,}000\text{ МГц}$, 20 пинов `LVCMOS33` по `hardware/tang_nano_9k.cst`).
2. **Силовой ключ (12 каналов):** $12\times$ Logic-Level N-MOSFET `IRLZ44N` (открывается напрямую от $3{,}3\text{ В}$), $12\times$ резистор затвора $R_g = 510\text{--}544\text{ Ом}$, $12\times$ обратный диод Шоттки `1N5819` (или `SS34`).
3. **Гальваническая развязка USB:** высокоскоростная оптопара `6N137` ($\mathrm{GaAs}\to\mathrm{Si}$, $Z(\mathrm{GaAs}) = 64 = K_P$) на линиях `UART_TX / UART_RX` (пины `17` и `18`).
4. **Катушки и УЗ-излучатели (12 вершин кубоктаэдра $O_2(3)$):**
   - $12\times$ медная катушка ($Z(\mathrm{Cu}) = 29$, $L = 100\text{ мкГн}$, $R_{25} \approx 33{,}1\text{ Ом}$, подводка витой парой $0{,}5\text{ м}$);
   - $12\times$ пьезокерамический излучатель $\mathrm{BaTiO_3}$ ($Z = 102$, резонанс на частоте кольца $52{,}734\text{ кГц}$).
5. **Каркас и реакционная камера:**
   - 3D-печатный держатель кубоктаэдра $O_2(3)$ из диэлектрического пластика **PLA / PETG** ($Z(\mathrm{C_3H_4O_2}) = 38$, нейлоновый крепёж M3 без металла);
   - чашка Петри с крышкой диаметром $90\text{ мм}$ из кварцевого или боросиликатного стекла $\mathrm{SiO_2}$ ($Z = 30$).
6. **Источник питания:** лабораторный БП $12\text{--}24\text{ В}$, $10\text{ А}$ ($180\text{--}240\text{ Вт}$) с конденсатором фильтра $470\text{ мкФ}$.

## 3. Команды полной аппаратной, схемотехнической и математической верификации стенда

```powershell
# 1. Формальное доказательство всех 20 узлов стенда в Lean 4 (0 sorry, 26/26 jobs):
Push-Location lean; lake build; Pop-Location

# 2. Потактовая RTL-симуляция чипа Tang Nano 9K и приёма калибровочного UART-кадра 0x08 (TOTAL HARDWARE ERRORS = 0):
C:\iverilog\bin\iverilog.exe -o hardware/cuboct_sim.vvp hardware/cuboctahedron_carrier_asic.v
C:\iverilog\bin\vvp.exe hardware/cuboct_sim.vvp

# 3. Схемотехническая SPICE-симуляция силового тракта MOSFET + катушка + диод Шоттки 1N5819 в LTspice:
Start-Process -FilePath "C:\Program Files\ADI\LTspice\LTspice.exe" -ArgumentList "-b hardware\kitchen_bench_mosfet_coil.cir" -Wait

# 4. Генерация 12 индивидуальных UART-кадров 0x06 и 52-минутного теплового расписания 0x08 через MCP-сервер:
python hardware/cuboctahedron_mcp_server.py --self-test

# 5. Полный прогон 14/14 тестов автономной библиотеки .NET 11 (AIGuiders.Physics.Core):
dotnet test -c Release _guiders_physics/AIGuiders.Physics.slnx
```
