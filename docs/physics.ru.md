## 1. Вывод размерности пространства $d=3$ и 72-битной ячейки

Вместо постулирования трёхмерности $d=3$ и непрерывного континуума $\mathbb{R}^3$ дискретный носитель выводит размерность пространства из единственного нетривиального диофантова замыкания локального причинного квадрата (`Core.lean`):

$$1 + 2^d = d^2 \iff d = 3.$$

Из $d=3$ без подгоночных параметров следуют все структурные инварианты решётки вакуума:

- **Размер элементарной ячейки:** $|S_{\mathrm{cell}}| = d^2 = 9$ узлов ($2^d = 8$ граничных узлов вокруг 1 центрального), что задаёт **72-битное состояние ячейки** ($9 \times 8 = 72$ бит).
- **Изотропная координационная сфера:** 12-лучевой кубооктаэдр $O_2$ ($N_{O_2}(3) = 2d(d-1) = 12$ диагональных лучей граней квадрата длины 2).
- **Проективный фазовый период:** $2^{d^2} = 2^9 = 512$ фазовых тактов на полный оборот, полупериод запрета Паули $\Phi_{\mathrm{Pauli}}(3) = 256$, вершина квадранта $Q_\square(3) = 128$ и порог дискретности Гейзенберга $\Delta\varphi_{\mathrm{disc}}(3) = 41$ ($|E_{\mathrm{Heis}}| = 2\cdot 41 - 1 = 81 = 3^4$).
- **Отношение баллистической скорости к скорости света:** $(c_0 / c)^2 = 16 / 9$ ($c_0 / c = 4 / 3$), откуда напрямую следуют квантовая граница Цирельсона $S_{\mathrm{QM}}^2 = (16/9)\,S_{\mathrm{LHV}}^2 = (2\sqrt{2})^2 = 8$ и космологический коэффициент вакуумного гало голономии $16/3$.

## 2. Постоянная тонкой структуры и спектр частиц/ядер

- **Алгебраическая постоянная тонкой структуры (`ContinuumPhysics.lean`, `alpha.py`):**
  На 12-лучевом кубооктаэдрическом роторе целочисленный объёмный топологический бюджет $12^2 - (d^2 - 2) = 144 - 7 = 137$ складывается с граничной поправкой голономии в квадратичном поле $\mathbb{Q}(\sqrt{2})$:

  $$\alpha_{\mathrm{fs}}^{-1} = 137 + \frac{1}{28 - 2\sqrt{2}} = \frac{103\,851 + 2\sqrt{2}}{758} \approx 137{,}036797 \quad (6{,}3\text{ ppm к CODATA } 137{,}035999).$$

- **Ядерные оболочки и ядро Паули чёрных дыр (`NuclearShells.lean`):**
  Воспроизводит магические числа по всем 8 периодам таблицы Менделеева, предсказывает остров стабильности сверхтяжёлых ядер при замыкании нейтронной оболочки $N = 184$, описывает фазы ядерной пасты и заменяет точечную гравитационную сингулярность несжимаемым ядром Паули с отношением плотностей $833 : 1$.

- **Онтогенез марковского одеяла и обратный компилятор ДНК (`OntogenyMutagenesis.lean`):**
  Формализует гомоморфизм 12-лучевого тензора внешних напряжений через марковское одеяло в 64-кодонный генетический код ($K_P(3) = 64$), мутагенез метилирования `CpG` и детерминированную компиляцию целевой топологии тканей в последовательности кодонов ДНК.
