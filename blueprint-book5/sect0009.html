Пусть \(\mathcal{O}_{\mathrm{vec}} = \{ (c_k, s_k, \alpha _k, \beta _k)\} _{k=1}^N \in \mathrm{List}\, (\mathbb {Z}^4)\) — произвольный конечный ансамбль двумерных волновых мод с суммарным базовым фазором \((C_\Sigma , S_\Sigma ) = \bigl(\sum _{k=1}^N c_k,\ \sum _{k=1}^N s_k\bigr)\), суммарным вектором радиальной производной \((A_\Sigma , B_\Sigma ) = \bigl(\sum _{k=1}^N \alpha _k,\ \sum _{k=1}^N \beta _k\bigr)\), вектором прямой волны \(W_+(\delta ) = (C_\Sigma + A_\Sigma \delta ,\ S_\Sigma + B_\Sigma \delta )\) и вектором встречной волны \(W_-(\delta ) = (C_\Sigma - A_\Sigma \delta ,\ S_\Sigma - B_\Sigma \delta )\) при сдвиге \(\delta \in \mathbb {Z}\). Тогда:

  1. Тождественное сокращение полной матрицы Грама \(\mathrm{MainAmount}_{\mathrm{vec}}(\delta )\) со всеми \(N^2\) перекрёстными слагаемыми: квадраты норм суммарных векторов \(U_{\mathrm{vec}}(\delta ) = |W_+(\delta )|^2\) и \(V_{\mathrm{vec}}(\delta ) = |W_-(\delta )|^2\) удовлетворяют:

    \begin{align} U_{\mathrm{vec}}(\delta ) + V_{\mathrm{vec}}(\delta ) & \equiv 2\, \mathrm{MainAmount}_{\mathrm{vec}}(\delta ) \; =\; 2\, \Bigl((C_\Sigma ^2 + S_\Sigma ^2) + \delta ^2(A_\Sigma ^2 + B_\Sigma ^2)\Bigr), \label{eq:math-vec-ocean-sum} \\ U_{\mathrm{vec}}(\delta ) - V_{\mathrm{vec}}(\delta ) & \equiv 4\, \bigl(C_\Sigma A_\Sigma + S_\Sigma B_\Sigma \bigr)\, \delta . \label{eq:math-vec-ocean-diff} \end{align}

  2. Тройная дихотомия \(M\)-этажного каскада \(\mathrm{SL}_2(\mathbb {Z})\): после прохождения пары \((U_{\mathrm{vec}}(\delta ), V_{\mathrm{vec}}(\delta ))\) через произвольный \(M\)-этажный каскад \(R \in \mathrm{List}\, \mathbb {Z}\) выходные амплитуды \(P_R = \operatorname {minkowskiCascadeP}(R, U_{\mathrm{vec}}(\delta ), V_{\mathrm{vec}}(\delta ))\) и \(Q_R = \operatorname {minkowskiCascadeQ}(R, U_{\mathrm{vec}}(\delta ), V_{\mathrm{vec}}(\delta ))\) удовлетворяют

    \begin{equation} \label{eq:math-cascade-diff-trichotomy} P_R - Q_R \; \equiv \; 4\, \Pi _-(R)\, \bigl(C_\Sigma A_\Sigma + S_\Sigma B_\Sigma \bigr)\, \delta , \end{equation}
    4.10

    а при \(q {\gt} 0\), \(P_R {\gt} 0\), \(Q_R {\gt} 0\) обращение в нуль интенсивности деструктивной интерференции \(I_q(P_R, Q_R, \mathcal{C}_q(\Delta \varphi )) = q(P_R - Q_R)^2 + 2 P_R Q_R(q + \mathcal{C}_q(\Delta \varphi ))\) эквивалентно тройной дихотомии:

    \begin{equation} \label{eq:math-counterwave-zero-iff-trichotomy} I_q\bigl(P_R,\, Q_R,\, \mathcal{C}_q(\Delta \varphi )\bigr) = 0 \; \Longleftrightarrow \; \Bigl(\Pi _-(R) = 0 \; \lor \; C_\Sigma A_\Sigma + S_\Sigma B_\Sigma = 0 \; \lor \; \delta = 0\Bigr) \; \land \; \operatorname {pauliPhaseDistNat}(q, \Delta \varphi ) = 0. \end{equation}
    4.11

  3. Две конструктивные модели и теорема о модельно-теоретической независимости \(\delta = 0\) от одних лишь встречно-волновых аксиом:

    • Модель 1 (коллинеарная модель \(\mathcal{O}_1 = [(1, 0, 1, 0)]\)): \((C_\Sigma , S_\Sigma ) = (1, 0)\), \((A_\Sigma , B_\Sigma ) = (1, 0)\), скалярное произведение \(C_\Sigma A_\Sigma + S_\Sigma B_\Sigma = 1 \ne 0\), откуда при \(\Pi _-(R) \ne 0\) равенство \(P_R = Q_R\) эквивалентно \(\delta = 0\);

    • Модель 2 (ортогональная модель \(\mathcal{O}_2 = [(1, 1, -1, 1)]\)): \((C_\Sigma , S_\Sigma ) = (1, 1) \perp (A_\Sigma , B_\Sigma ) = (-1, 1)\), скалярное произведение \(C_\Sigma A_\Sigma + S_\Sigma B_\Sigma = 1\cdot (-1) + 1\cdot 1 = 0\), и на ненулевом сдвиге \(\delta = 1 \ne 0\) выполняются \(U_{\mathrm{vec}}(1) = 4 {\gt} 0\), \(V_{\mathrm{vec}}(1) = 4 {\gt} 0\), \(P_R = Q_R\) и \(I_q(P_R, Q_R, \mathcal{C}_q(2q)) = 0\).

    Следовательно, утверждение \(\delta = 0\) модельно-теоретически независимо от аксиом встречно-волновой симметрии и каскада \(\mathrm{SL}_2(\mathbb {Z})\) без дополнительного аналитического закона, исключающего ортогональность \((C_\Sigma , S_\Sigma ) \perp (A_\Sigma , B_\Sigma )\).

Тождества 4.8–4.11 и свойства моделей \(\mathcal{O}_1, \mathcal{O}_2\) следуют из билинейности скалярного произведения и факторизации разности башни Паде.
