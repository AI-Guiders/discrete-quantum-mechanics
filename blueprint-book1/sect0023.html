При \(d = 3\) на кольце \(\mathbb {Z}_{512}\) и оболочке кубооктаэдра \(O_2(3)\) выполняются следующие соотношения:

  1. Седло химической связи \(Q_\square (3) = 128\) и закон Гесса: на участке \(\Delta \varphi \in [0, 256]\) чётная связывающая проекция \(\mathcal{C}_3(\Delta \varphi ) = 128 - \Delta \varphi \) убывает от \(+128\) (ковалентный минимум \(\Delta \varphi = 0\)) через точку перегиба седла реакции \(\Delta \varphi ^* = Q_\square (3) = 128\) (\(\mathcal{C}_3(128) = 0\), \(\mathcal{S}_3(128) = +128\)) к антисвязывающему полюсу Паули \(\Delta \varphi = 256\) (\(\mathcal{C}_3(256) = -128\)), а поскольку энтальпия реакции является точной \(0\)-коцепью (\(d_1(d_0 H) \equiv 0\)), суммарный тепловой эффект любого замкнутого каталитического цикла тождественно равен нулю (закон Гесса).

  2. Кратность ковалентных связей \(\{ 1, 2, 3\} \) и правила орбитальной симметрии Хюккеля и Вудворда–Хоффмана (\(4n + 2\) и \(4n\)): максимальная устойчивая кратность локализованной ковалентной связи между двумя атомами главной группы равна \(d = 3\) (\(1\) общая вершина для \(\sigma \)-связи, \(2\) вершины ребра для \(\pi \)-связи, \(3\) вершины треугольной грани \(K_3\) для тройной связи). На замкнутом сопряжённом цикле с четверть-периодным шагом \(Q_\square (3) = 128\) на каждый \(\pi \)-электрон и спиновым синглетным полуоборотом Паули \(+\Phi _{\mathrm{Pauli}}(3) = +256\) полная кольцевая фаза равна:

    \begin{equation} \label{eq:mono-huckel-ring-phase} \Phi _{\mathrm{ring}}(N_\pi ) \; \equiv \; Q_\square (3)\, N_\pi + \Phi _{\mathrm{Pauli}}(3) \; \equiv \; 128\, N_\pi + 256 \pmod{512}, \end{equation}
    6.9

    что даёт ароматический связывающий максимум \(\mathcal{C}_3(0) = +128\) при \(N_\pi = 4n + 2\) и антиароматический мёбиусовский полюс \(\mathcal{C}_3(256) = -128\) при \(N_\pi = 4n\) (правила дисротаторного и конротаторного замыкания Вудворда–Хоффмана).

  3. Сверхпроводящее спаривание Купера \(2e\) на антиподальных лучах кубооктаэдра и оболочки ВТСП: два вихревых узла с противоположными импульсами \((\mathbf{k}, -\mathbf{k})\) на центросимметричных лучах \(\pm \mathbf{e} \in O_2(3)\) и антиподальным спиновым сдвигом \(+\Phi _{\mathrm{Pauli}}(3) = +256\) образуют синглетную пару Купера удвоенного заряда \(2e = (c_0/c)^2 e\) с нулевым током рассеяния и полным конструктивным возрождением Ааронова–Бома на полуобороте Паули:

    \begin{align} \mathcal{S}_3(\Delta \varphi ) + \mathcal{S}_3(-\Delta \varphi ) & \equiv 0, \label{eq:mono-cooper-odd-cancel} \\ \mathcal{C}_3\bigl(2\, \Phi _{\mathrm{Pauli}}(3)\bigr) & = \mathcal{C}_3(512) \; =\; +128, \label{eq:mono-cooper-revival} \end{align}

    при замыкании формульных единиц сверхпроводников \(Z(\mathrm{TiNi}) = 50\), \(Z(\mathrm{MgB_2}) = 22\), \(Z(\mathrm{CuO_2}) = 45\), \(Z(\mathrm{CaCuO_2}) = 65\), \(Z(\mathrm{FeS}) = 42 = S_2(3)\).

  4. Когерентное схлопывание кулоновского барьера в \(587\) раз: при синфазной фокусировке всех \(12\) лучей кубооктаэдра на фазе когерентного резонанса

    \begin{align} A_{\mathrm{coh}}(3) & = Q_\square (3) + |N(3)| - 1 \; =\; 128 + 11 \; =\; 139, \label{eq:mono-acoh-139} \\ \bigl(\mathcal{C}_3(139),\ \mathcal{S}_3(139)\bigr) & = (-11,\ +117), \label{eq:mono-acoh-cs} \end{align}

    двенадцать отрицательных косинусных вкладов \(12 \times (-11) = -132\) снижают импеданс в центре ячейки с \(D_{\max }(3) = 6\, 823\, 936\) до \(D_{\mathrm{coh}}(3) = 11\, 616\) с коэффициентом подавления барьера:

    \begin{equation} \label{eq:mono-587-collapse} \left\lfloor \frac{D_{\max }(3)}{D_{\mathrm{coh}}(3)} \right\rfloor \; =\; \left\lfloor \frac{6\, 823\, 936}{11\, 616} \right\rfloor \; =\; 587 \; =\; 512 + 3 \times 25 \; =\; N_{\mathrm{ring}}(3) + d\cdot d_{\mathrm{out}}(E)^2. \end{equation}
    6.14

Proof ▶

В пункте (1) \(\mathcal{C}_3(128) = 128 - 128 = 0\), а равенство \(\sum _{e\in \gamma }(H_v - H_u) = 0\) на любом замкнутом цикле \(\gamma \) следует из \(d_1\circ d_0 \equiv 0\).

В пункте (2) пересечение двух кубооктаэдров со сдвигом центров в \(\mathbb {Z}^3\) содержит не более \(3\) общих вершин треугольной грани \(K_3\) (так как квадратная грань из \(4\) вершин не лежит на одном радиальном конусе с общей вершиной без совпадения центров). Для кольцевой фазы 6.9 при числе \(\pi \)-электронов \(N_\pi = 4n + 2\) подстановка в \(128\, N_\pi + 256\) даёт:

\[ \Phi _{\mathrm{ring}}(4n + 2) \; =\; 128(4n + 2) + 256 \; =\; 512n + 256 + 256 \; =\; 512(n + 1) \; \equiv \; 0 \pmod{512}, \]

где \(\mathcal{C}_3(0) = +128\) (максимум ароматического связывания Хюккеля и термически разрешённое дисротаторное замыкание). Напротив, при \(N_\pi = 4n\) получаем:

\[ \Phi _{\mathrm{ring}}(4n) \; =\; 128(4n) + 256 \; =\; 512n + 256 \; \equiv \; 256 \pmod{512}, \]

где \(\mathcal{C}_3(256) = -128\) (антисвязывающий полюс Паули), для компенсации которого требуется дополнительный мёбиусовский (конротаторный) полуоборот \(+256\) (\(256 + 256 \equiv 0 \pmod{512}\)).

В пункте (3) нечётность \(\mathcal{S}_3(-\Delta \varphi ) = -\mathcal{S}_3(\Delta \varphi )\) обнуляет рассеяние, а удвоение фазы \(2\times 256 = 512 \equiv 0 \pmod{512}\) возвращает \(\mathcal{C}_3(512) = +128\). В пункте (4) при \(\Delta \varphi = 139\) проекция равна \(\mathcal{C}_3(139) = 128 - 139 = -11\), откуда \(D_{\mathrm{coh}} = 11\, 616\) и \(\lfloor 6\, 823\, 936 / 11\, 616 \rfloor = 587\).
