3.1 Функционально полный базис Поста на двух каналах \(\mathbb {Z}_{512}\) и полиномиальная редукция 3-SAT

На антиподальной подгруппе полюсов \(\{ 0, \Phi _{\mathrm{Pauli}}(3)\} = \{ 0, 256\} \subset \mathbb {Z}_{512}\) чётная проекция принимает противоположные граничные значения

\begin{equation} \label{eq:mono-boolean-poles} \mathcal{C}_3(0) \; =\; +128 \quad (\text{булева истина } 1), \qquad \mathcal{C}_3(256) \; =\; -128 \quad (\text{булева ложь } 0). \end{equation}
3.1

На треугольных гранях \((\psi _1, \psi _2, \psi _3) \in \{ 0, 256\} ^3\) девятибитный сумматор разделяет вычисления на два ортогональных алгебраических канала:

  1. Канал 1 (аффинный линейный класс Поста \(L\) — сложение фаз до оператора \(\mathcal{C}_3\)): полупериодный сдвиг \(\mathrm{NOT}(\psi ) = (\psi + 256) \bmod 512\) меняет знак проекции (\(\mathcal{C}_3(\psi + 256) = -\mathcal{C}_3(\psi )\)), а сложение фаз по модулю \(512\) задаёт трёхаргументную чётность \(\mathrm{XOR}_3\) по мультипликативному тождеству

    \begin{equation} \label{eq:mono-pre-rotator-xor} Q_\square (3)^2\, \mathcal{C}_3(\psi _1 + \psi _2 + \psi _3) \; \equiv \; \mathcal{C}_3(\psi _1)\, \mathcal{C}_3(\psi _2)\, \mathcal{C}_3(\psi _3), \end{equation}
    3.2

    где подгруппа полюсов \((\{ 0, 256\} , + \bmod 512) \cong (\mathbb {F}_2, \oplus )\) (\(256 + 256 \equiv 0 \pmod{512}\)).

  2. Канал 2 (нелинейный пороговый класс — сложение проекций после оператора \(\mathcal{C}_3\) с целочисленным делением на \(N_{\mathrm{ring}}(3) = 512\)): для дефекта грани \(\Delta _{\mathrm{3SAT}}(\psi _1, \psi _2, \psi _3) := Q_\square (3) - \bigl(\mathcal{C}_3(\psi _1) + \mathcal{C}_3(\psi _2) + \mathcal{C}_3(\psi _3)\bigr)\) в силу равенства \((1 + d)Q_\square (3) = 4 \times 128 = 512 = N_{\mathrm{ring}}(3)\) неполные частные целочисленного деления на \(512\) со знаком к нулю задают безветвевые операторы дизъюнкции и конъюнкции:

    \begin{align} q_{\mathrm{OR}}(\psi _1, \psi _2, \psi _3) & := \mathrm{tdiv}\bigl(\Delta _{\mathrm{3SAT}}(\psi _1, \psi _2, \psi _3),\, 512\bigr) \in \{ 0, 1\} , \label{eq:mono-post-rotator-or-and} \\ q_{\mathrm{AND}}(\psi _1, \psi _2, \psi _3) & := \mathrm{tdiv}\Bigl(128 + \sum _{k=1}^3 \mathcal{C}_3(\psi _k),\, 512\Bigr) \in \{ 0, 1\} . \label{eq:mono-post-rotator-and} \end{align}

  • thm4_boolean_post_completeness_3sat_reduction_and_channel_orthogonality

При \(d = 3\) на полюсах \(\{ 0, 256\} ^3 \subset \mathbb {Z}_{512}^3\) выполняются следующие точные соотношения:

  1. Во всех \(2^3 = 8\) состояниях \(\{ 0, 256\} ^3\) частное \(q_{\mathrm{AND}}\) равно \(1\) исключительно на \((0,0,0)\) и \(0\) на остальных \(7\) октантах, а частное дефекта \(q_{\mathrm{OR}}\) равно \(0\) на всех \(7\) выполняющих октантах дизъюнкта \((l_1 \lor l_2 \lor l_3)\) и равно \(1\) (\(\Delta _{\mathrm{3SAT}} = 512\)) исключительно на запрещённом октанте \((256, 256, 256)\). По теореме Поста совокупность Канала 1 и Канала 2 функционально полна (выходит из всех пяти предполных классов \(T_0, T_1, S, M, L\)), а выполнимость любой формулы 3-SAT из \(M\) дизъюнктов эквивалентна равенству:

    \begin{equation} \label{eq:mono-3sat-sum-zero} \sum _{m=1}^M q_{\mathrm{OR}}(\psi _{m,1}, \psi _{m,2}, \psi _{m,3}) \; =\; 0. \end{equation}
    3.5

  2. Прямое вычисление \(q_{\mathrm{OR}} = \mathrm{tdiv}(\Delta _{\mathrm{3SAT}}, 512)\) отбрасывает трёхзначный остаток и склеивает \(2^3 - 1 = 7\) различных выполняющих октантов в один выход \(q_{\mathrm{OR}} = 0\), порождая на обратном конусе глубины \(T\) шагов ветвление неразличимых прообразов вдоль каждого луча:

    \begin{equation} \label{eq:mono-3sat-7t-branching} r(\Delta _{\mathrm{3SAT}}) \in \{ -256,\ 0,\ +256\} , \qquad N_{\mathrm{branch}}(T) \; =\; (2^3 - 1)^T \; =\; 7^T \quad \bigl(7^3 = 343 \text{ при } T = 3\bigr). \end{equation}
    3.6

  3. Для четвёрки дизъюнктов 3-SAT, кодирующей одно линейное уравнение чётности Канала 1 (\(x_1 \oplus x_2 \oplus x_3 = 0\)), сумма линейных проекций \(\mathcal{C}_3\) по всем четырём дизъюнктам тождественно равна нулю во всех \(8\) октантах (\(\mathrm{xor4LinearGradientSum} \equiv 0\)), образуя замкнутые ядра чётности с нулевым линейным откликом.

Proof ▶

В пункте (1) при \(\psi _k \in \{ 0, 256\} \) проекции \(\mathcal{C}_3(\psi _k)\) принимают значения \(+128\) (при \(\psi _k = 0\)) и \(-128\) (при \(\psi _k = 256\)). На тройке \((0,0,0)\) сумма \(128 + 3\times 128 = 512\) при делении на \(512\) даёт \(q_{\mathrm{AND}} = 1\), а на остальных семи тройках сумма принадлежит \(\{ -256, 0, +256\} \subset (-512, 512)\), откуда \(q_{\mathrm{AND}} = 0\). Двойственным образом \(\Delta _{\mathrm{3SAT}} = 128 - \sum _{k=1}^3 \mathcal{C}_3(\psi _k)\) равен \(512\) только на \((256,256,256)\) (\(q_{\mathrm{OR}} = 1\)) и принадлежит \(\{ -256, 0, +256\} \) на всех семи выполняющих наборах (\(q_{\mathrm{OR}} = 0\)). В пункте (2) отображение \(\mathrm{tdiv}(\cdot , 512)\) переводит все семь выполняющих наборов с остатками \(r \in \{ -256, 0, +256\} \) в одно значение \(0\), что на глубине \(T\) даёт \(7^T\) прообразов. В пункте (3) в четырёх дизъюнктах уравнения чётности каждая переменная входит дважды без отрицания и дважды с отрицанием, а поскольку \(\mathcal{C}_3(\psi + 256) = -\mathcal{C}_3(\psi )\), сумма проекций по всем четырём дизъюнктам тождественно обращается в нуль в каждом из \(8\) октантов.
