2.2 Вывод классического интеграла Римана и формулы Ньютона–Лейбница в макропределе \(N \to \infty \)

Пусть \(V_{O_2}(3, N) = 1 + \sum _{k=1}^{N} (10k^2 + 2)\) — полное число узлов в \(N\)-слойном причинном шаре кубооктаэдра. Тогда:

  1. Точный целочисленный объём шара удовлетворяет полиномиальному тождеству третьей степени без остатка:

    \begin{align} 3\, V_{O_2}(3, N) & = 10\, N^3 + 15\, N^2 + 11\, N + 3, \label{eq:mono-ball-polynomial} \\ \bigl(V_{O_2}(3,1),\ V_{O_2}(3,2),\ V_{O_2}(3,3)\bigr) & = (13,\ 55,\ 147). \label{eq:mono-ball-123} \end{align}

  2. При макроскопическом масштабировании шага решётки \(h = R / N \to 0\) нормированная сумма по сферическим слоям кубооктаэдра сходится к непрерывному радиальному интегралу Римана \(\int _0^R r^2\, \mathrm{d}r = R^3 / 3\) с точным главным коэффициентом \(|N(3)| - (c_0/c)^2 = 12 - 2 = 10\):

    \begin{equation} \label{eq:mono-archimedes-limit} \lim _{N \to \infty } \frac{1}{10\, N^3} \sum _{k=1}^{N} S_k(3) \; =\; \lim _{N \to \infty } \frac{V_{O_2}(3, N) - 1}{10\, N^3} \; =\; \frac{1}{3} \; =\; \int _0^1 x^2\, \mathrm{d}x. \end{equation}
    2.11

  3. Для любой дискретной первообразной \(F(\Phi ) = \sum _{\varphi =0}^{\Phi -1} f(\varphi )\) на кольце \(\mathbb {Z}_{512}\) выполняется точная формула Ньютона–Лейбница без ошибки округления:

    \begin{align} \sum _{\varphi =a}^{b-1} \Delta F(\varphi ) & = F(b) - F(a), \label{eq:mono-newton-leibniz} \\ \oint _{\mathbb {Z}_{512}} \Delta F(\varphi ) & = 0. \label{eq:mono-newton-leibniz-loop} \end{align}
Proof ▶

Подставляя формулу суммы квадратов \(6\sum _{k=1}^N k^2 = N(N+1)(2N+1) = 2N^3 + 3N^2 + N\) в определение \(3 V_{O_2}(3, N) = 3 + 5\cdot 6\sum _{k=1}^N k^2 + 6N\), получаем \(3 + 5(2N^3 + 3N^2 + N) + 6N = 10N^3 + 15N^2 + 11N + 3\), что доказывает 2.9. Деление \((V_{O_2}(3,N) - 1)\) на \(10N^3\) даёт \(\frac{1}{3} + \frac{1}{2N} + \frac{11}{30N^2} \to \frac{1}{3}\) при \(N \to \infty \), доказывая 2.11. Равенство 2.12 следует из телескопического сокращения последовательных разностей \(\Delta F(\varphi ) = F(\varphi +1) - F(\varphi )\).
