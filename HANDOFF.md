## 2. Установлено замерами

1. **Знак в дорожках.** `projected_collision_impulse` читал дорожки как $0\ldots511$ без
   `signed_from_mod`. Для 56% ячеек поворот применялся к неверному вектору:
   $(500,14)$ вместо $(-12,14)$ → импульс $(-74,-275)$ вместо $(9,4)$.
   После правки: `verify` — **150 проверок, 14 провалов** (до правки было 0); упали только
   динамические (Floor0/Floor1, аннигиляция, CE-C-04, QM_double_slit, Local_gates, LadderConservation).
2. **$\mathbb{Z}_4$ точная** при симметричном округлении: `step(i·f) == i·step(f)`, 0 из 16384
   дорожек, то же для $-1$.
3. **$q=(u^2+v^2)\bmod 512$** не зависит от разреза и сохраняется в 94% ячеек за 32 такта
   при движущемся поле — тень симметрии, не инвариант.
4. **Норма.** При открытых воротах $\sum|z|^2$ растёт $768\to2{,}3\times10^4$ за 512 тактов,
   поле упирается в предел кольца ($\rho\approx58$ при 64).
5. **Ворота — детектор рассогласования, не энергии.** $\Phi=0$ при $\psi=0°$ и $180°$;
   растёт с углом $\psi$ между ячейкой и суммой соседей. Один узел на $90°$ в **плотной**
   заплате открывает ворота при $\rho\approx0{,}12$ ($a\approx0{,}25$) — ниже потолка A7.
   На гладких конфигурациях (волна, ступенька, вихрь) $\Phi$ насыщается около 31 и порога 41
   не достигает ни при какой амплитуде: $\zeta_i$ и $\rho^2$ оба $\propto\rho^2$, отношение выходит на предел.
6. **Из одного четверть-оборота рождается устойчивый сгусток ~30 ячеек** (заплата $5^3$, $a=0{,}3$):
   ворота горят, структура живёт все 512 тактов и не разрастается. Намотка в центре — **NaN**:
   при $|z|\approx5$ фаза теряет разрядность.

## 3. Опровергнуто (мои ошибки — не повторять)

- «Паули структурно недостижим» — считала по книжному A7; автомат его в состоянии не держит.
- «$\Phi\approx1$ при $\rho\le1$» — сырой максимум 22 у канонического сида; недобор меньше чем вдвое.
- «сид слабый, поднять амплитуду» — $\Phi$ не растёт по амплитуде, он насыщается.
- проба на **бегущей волне** негодна: у волны $\zeta$ вещественна, $\Phi=0$ по симметрии,
  всё ненулевое там — остаток квантования.
- первый замер гейта без снятия `mod 512`: значения 256 были **заворотом**, не насыщением.
- $v_a=2c_0$ — частота сэмплирования, выданная за частоту моды; нарушает A1.

Диаграмма гейта — самодостаточный кусок (без внешних файлов):

```python
import math, torch
from mt_ca.config import MConfig
from mt_ca.fixed_point import encode_spinor
from mt_ca.projected_collision import (holonomy_zeta_int, int_neighbor_sum,
                                       k_p_int, rho2_int, signed_lanes)

cfg = MConfig.for_stencil("fcc", heisenberg_floor=False)
kp, N, size, half = k_p_int(cfg), 1 << cfg.mod_bits, 12, 6

def phi_at(step, a):
    ramp = torch.ones(size, dtype=torch.float64); ramp[:half] = step
    ph = 2.0 * math.pi * ramp.reshape(1, 1, size) / N
    z = torch.zeros(size, size, size, 2, dtype=torch.complex128)
    z[..., 0] = a * torch.exp(1j * ph); z[..., 1] = a * torch.exp(1j * ph)
    f = encode_spinor(z.to(torch.complex64), frac_bits=cfg.frac_bits, mod_bits=cfg.mod_bits)
    fs = signed_lanes(f, cfg); u0, v0 = fs[..., 0], fs[..., 1]
    sn = int_neighbor_sum(fs, cfg.stencil)
    zr, zi = holonomy_zeta_int(u0, v0, sn[..., 0], sn[..., 1], frac_bits=cfg.frac_bits)
    d = zr + rho2_int(u0, v0, frac_bits=cfg.frac_bits) + kp
    d = torch.where(d > 0, d, torch.ones_like(d))
    return float(((kp * zi).double() / d.double()).abs().max())
```

Ключевой факт для продолжения: **амплитуда не открывает ворота, открывает рассогласование
$\psi\approx90°$ внутри плотного окружения.** Все канонические сиды (океан, маска, `VORTEX_P`)
гладкие или разреженные — поэтому заморожены, и это не дефект сида.
