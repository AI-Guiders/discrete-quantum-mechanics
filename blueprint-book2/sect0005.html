1.4 Пошаговый протокол изготовления в чистой комнате и контрольный A/B-эксперимент

Слой каскада

Материал и геометрия

Инвариант ДКМ

Физическая функция

1. Входная оптика

Кварцевый микрорельеф \(O_2(3)\)

\(n_1/n_2 = 9/8\), \(T = 288/289\)

Просветление \(99{,}65\% \) и захват 12 лучей

2. Делитель кванта

Кристаллический тетрацен \(\mathrm{C_{18}H_{12}}\)

\(Z = 120\), \(441\text{ нм} \to 2\times 882\text{ нм}\)

Деление синего фотона \(S_1 \to T_1 + T_1\) (\(\hat{n}_E=0\))

3. Седловой мост

Оксид/силанол \(\mathrm{SiO_4} / [\mathrm{AlO_4H}]\)

\(120 + 8 = 128 = Q_\square \), \(Z = 46\)

Барьер Паули \(46^2 {\gt} 2048\) для \(S_1\), окно для \(T_1\)

4. Базовый переход

Кремний IBC-\(\mathrm{Si}\) (тыльные контакты)

\(Z = 14\), \(\lambda _{\mathrm{Si}} = 27\times 41 = 1107\text{ нм}\)

Приём \(2\times 882\text{ нм}\) с запасом \(15^2 = 225\text{ нм}\)

  1. Базовая подложка (Слой 4): пластина кристаллического кремния \(n\)-типа \(\mathrm{Si}(100)\) со встречно-штыревыми тыльными контактами (IBC-\(\mathrm{Si}\), \(Z(\mathrm{Si})=14\), \(\lambda _{\mathrm{Si}} = 1107\text{ нм}\), удельное сопротивление \(1\text{--}5\ \Omega \cdot \text{см}\)), очистка RCA + HF-dip до атомарно гладкой грани \(\mathrm{Si}(100)\).

  2. Седловой пассивирующий мост и контрольный A/B-тест противофазного порога (Слой 3): выращивание ультратонкого (\(0{,}8\text{--}1{,}2\text{ нм}\), \(2\text{--}3\) координационных монослоя) туннельного диэлектрического моста на передней грани \(\mathrm{Si}(100)\) в двух режимах:

    • Контрольный образец A (\(Z = 45\), затвор Паули открыт для утечки): дегидрированный сухой оксид \(\mathrm{AlO_4}\) (\(Z = 13 + 32 = 45\), вакуумный отжиг \({\gt} 670\text{ К}\), \(45^2 = 2025 {\lt} 2048 = K_P(3)^2/2\)), допускающий сброс неразделённого синглета \(S_1\);

    • Целевой образец B (\(Z = 46\), седловой противофазный замок): тетраэдрический силанол/кремнезём \(\mathrm{SiO_4}\) (\(Z = 14 + 32 = 46\)) либо водородно-пассивированный ALD \([\mathrm{AlO_4H}]\) (\(Z = 13 + 32 + 1 = 46\), отжиг в форминг-газе \(\mathrm{H_2}/\mathrm{N_2}\) при \(520\text{--}570\text{ К}\), \(46^2 = 2116 {\gt} 2048\)), запирающий неразделённый синглет \(S_1\) и выводящий тетрацен (\(Z=120\)) через терминальный атом кислорода (\(Z=8\)) точно на седло четверти кольца \(120 + 8 = 128 = Q_\square (3)\).

  3. Нанесение слоя деления синглетов (Слой 2): термическое напыление в вакууме (\(\le 10^{-6}\text{ Па}\)) сублимированного тетрацена \(\mathrm{C_{18}H_{12}}\) (\(Z = 120\), толщина \(30\text{--}70\text{ нм}\), скорость \(0{,}2\text{--}0{,}5\text{ \AA /с}\) при температуре подложки \(295\text{--}300\text{ К}\)) на седловой мост с ориентацией осей вдоль ортогональных лучей \(O_2(3)\) (\(\Delta \varphi = 128 \implies \mathcal{C}_3(128) = 0\)).

  4. Входная просветляющая инкапсуляция (Слой 1): кварцевое покрытие (\(\mathrm{SiO_2}\), \(Z = 30\)) с 12-лучевым микрорельефом кубооктаэдра \(O_2(3)\) и отношением показателей преломления \(n_1/n_2 = 9/8\) (\(T_{\mathrm{Fresnel}} = 288/289 \approx 99{,}654\% \)), наносимое без выноса образца на воздух.
